Sizzle & Serve — run The Golden Skillet diner in a 3-minute dinner rush. Orders roll in on the board: grab buns, patties, lettuce, tomatoes, cheese and fries from the pantry, chop the veg, grill the patties, fry the fries, build each dish on the assembly plate and ring the serve bell before the customer walks out. Serve fast for a time bonus and chain serves for a combo — but let an order expire and you lose a heart. Three strikes and the kitchen closes early.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network, just static files.

WASD / arrows move the chef · E or click: use a station · Q: clear the plate · P: pause · M: mute · R: restart.
